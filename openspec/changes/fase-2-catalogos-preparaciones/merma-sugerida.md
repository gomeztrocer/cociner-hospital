# Corrección registrada para la Fase 2: merma sugerida

Esta corrección queda documentada, pero no se implementa en la Fase 1.

- CocinerHosp debe conservar la lógica o tabla actual que propone mermas.
- Para una proteína nueva, el valor propuesto debe identificarse como **Merma sugerida**.
- La persona usuaria podrá aceptar la sugerencia, modificarla o dejar la merma sin definir.
- Una sugerencia no debe convertirse en un valor obligatorio ni heredarse de otra proteína sin relación.
- Las calculadoras y los catálogos solo se modificarán cuando se autorice expresamente la Fase 2.
